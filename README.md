## The slogan

> Your Solana wallet, finally awake — it handles the paying and swapping, you handle the living.

16 words, 94 characters, one line. A wallet agent that wakes up and does the
paying and swapping, while you get on with living — plain words, no crypto
clichés, nothing promised the wallet cannot deliver.

## Run

```sh
python3 -P -s main.py   # writes /output/entry.txt
```

`main.py` is Python 3.13 stdlib only, deterministic, with no network and no
model calls. It validates the RULES.txt gate (1–140 characters, at most 20
words, a single line, not only whitespace) before writing. `ENTRY_OUTPUT`
overrides the output path for local testing.
